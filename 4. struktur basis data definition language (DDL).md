### 1. Tipe Data

| Tipe Data | Fungsi | Contoh |
|---|---|---|
| Varchar | Digunakan untuk teks dengan panjang yang bervariasi. | `nama_siswa VARCHAR(100)` |
| Char | Digunakan untuk teks dengan panjang relatif tetap. | `jenis_kelamin CHAR(1)` |
| INT | Digunakan untuk bilangan bulat. | `tingkat INT` |
| Date | Digunakan untuk tanggal. | `tanggal_lahir DATE` |
| Time | Digunakan untuk waktu. | `jam_mulai TIME` |
| Decimal | Digunakan untuk angka desimal yang membutuhkan ketelitian. | `nilai_akhir DECIMAL(5,2)` |
| Year | Dapat digunakan untuk nilai tahun pada kebutuhan tertentu. | `-` |

### 2. Constraint

| Constraint | Fungsi | Contoh |
|---|---|---|
| NOT NULL | Digunakan jika sebuah field wajib memiliki nilai. | `nama_siswa VARCHAR(100) NOT NULL` |
| UNIQUE | Digunakan apabila suatu nilai tidak boleh sama dengan record lainnya. | `nisn VARCHAR(20) UNIQUE` |
| DEFAULT | Memberikan nilai awal secara otomatis. | `status VARCHAR(20) DEFAULT 'Aktif'` |
| AUTO_INCREMENT | Digunakan untuk menghasilkan nomor secara otomatis. | `-` |

### 3. Rangkuman Perintah SQL

| Perintah | Fungsi |
|---|---|
| `CREATE TABLE` | Membuat tabel |
| `PRIMARY KEY` | Menentukan identitas utama |
| `FOREIGN KEY` | Membentuk referensi antar-tabel |
| `REFERENCES` | Menentukan tabel referensi |
| `NOT NULL` | Data wajib memiliki nilai |
| `UNIQUE` | Nilai tidak boleh duplikat |
| `DEFAULT` | Memberikan nilai bawaan |
| `AUTO_INCREMENT` | Menghasilkan nomor otomatis |
| `ALTER TABLE` | Mengubah struktur tabel |
| `ADD` | Menambah field |
| `MODIFY` | Mengubah definisi field |
| `DROP COLUMN` | Menghapus field |
| `DROP TABLE` | Menghapus tabel |
| `SHOW TABLES` | Menampilkan tabel |
| `DESCRIBE` | Menampilkan struktur tabel |
| `SHOW CREATE TABLE` | Menampilkan definisi SQL tabel |
